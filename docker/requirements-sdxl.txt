# Isolated deps for the SDXL-Lightning image server (docker/sdxl_server.py).
#
# Kept OUT of pyproject.toml and out of .venv-image for two separate reasons:
#   - the diffusers/torch stack here would collide with the doc-kg/diary-kg
#     transformers pins in the project env;
#   - mflux (.venv-image) pins its own transformers range, so the two image
#     backends cannot share one venv either.
# `make sdxl-server` builds .venv-sdxl from this file.
#
# Portable, unlike requirements-image.txt: torch's default wheels cover CPU,
# CUDA and Apple MPS, and sdxl_server resolves cuda -> mps -> cpu. This is the
# image backend for anything that is not Apple Silicon.
#
# Mirrors gutenberg_kg/docker/requirements-sdxl.txt.
